# Customer Churn / Sales Trend Analysis

## Project Overview
An end-to-end E-commerce Sales Analysis project using Python to identify revenue trends, product category performance, and valuable customers.

## Objectives
- Analyze monthly revenue trends.
- Identify top-performing product categories.
- Calculate month-over-month revenue growth.
- Identify the top 10% valuable customers.
- Generate actionable business recommendations.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
A simulated E-commerce sales dataset containing 2,000 orders.

## Key Analysis
- Monthly Revenue Analysis
- Category-wise Sales Analysis
- Customer Spending Analysis
- Revenue Contribution Analysis
- Business Recommendations

## Project Deliverables
- Google Colab Notebook
- Business Brief PDF
- Sales Analysis Dashboard

## Conclusion
This project demonstrates practical data analysis skills and business intelligence techniques to support data-driven decision-making.
